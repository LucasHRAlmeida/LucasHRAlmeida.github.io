## Convenção

Cada pasta deve conter:

- `README.md`: identificação, finalidade e links.
- `tracks.json`: espelho estruturado das faixas, quando disponível.
- `sources.md`: evidências de proveniência, data de captura e método de sincronização.

Nada é reproduzido automaticamente; a reprodução depende da iniciativa do visitante.
