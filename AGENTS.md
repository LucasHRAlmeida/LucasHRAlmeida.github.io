# Sala VIA — orientações para agentes de frontend

A raiz de `iniciativa-via.com` é servida por `index.html` neste repositório. Preserve a identidade editorial, os destinos dos links e o funcionamento dos players ao alterar a interface.

## Referência técnica

Consulte as orientações pertinentes em [modern-web-guidance](https://github.com/LucasHRAlmeida/modern-web-guidance-google-instructions-/tree/main/skills/modern-web-guidance) antes de editar HTML, CSS ou JavaScript do navegador. Para esta página, comece pelos guias de tipografia, cor, adaptação de tela e redução de ruído. Use guias específicos quando a tarefa envolver outra API. A referência informa a implementação; a direção visual segue o briefing do titular e a página existente.

## Entrega e verificação

- Mantenha conteúdo e navegação em HTML legível, com JavaScript como aprimoramento.
- Teste a composição em desktop e celular, em 320 CSS px e com zoom de 200% e 400%. Nenhum texto, controle, iframe ou card deve ser cortado ou gerar rolagem horizontal.
- Prefira dimensões fluidas, `min-height` para áreas com texto, consultas de contêiner quando couber e `aspect-ratio` para mídia. Preserve alvos de toque e contraste.
- Registre no PR o que mudou, o que foi conferido e qualquer limitação. A revisão visual do titular antecede a publicação da raiz.
